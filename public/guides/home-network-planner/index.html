Practical next steps

    Understand the basic home network layout

    In a typical home, the internet service reaches a modem or fibre ONT. A router connects your home network to that service and provides wired ports and often Wi-Fi. Other devices connect to the router directly, through a switch, or through additional access points or mesh nodes.

    A network switch adds Ethernet ports. A wireless access point adds Wi-Fi coverage at a location connected to the network, often by Ethernet. A mesh system uses multiple coordinated Wi-Fi units; the units need a suitable connection between them, either wireless or wired if supported.

    Place equipment sensibly

    • Keep the main router in an open, raised location where practical—not inside a cupboard or behind a television.
    • Place wireless mesh nodes where they still receive a useful connection from the main unit or another node.
    • Use Ethernet for stationary, latency-sensitive devices when practical.
    • Avoid placing access points or mesh nodes beside large metal objects, dense obstacles or sources of interference.
    • Change one placement at a time and test from the rooms where people actually use the network.

    Before you install or buy

    1. Check the speed and connection type provided by your ISP.
    2. Check the router, ONT and device port capabilities.
    3. Decide which devices benefit most from wired connections.
    4. Plan safe cable routes and power access for each device.
    5. Test the current network before purchasing additional equipment.

    Important

    This planner provides a learning recommendation based on your answers. It does not inspect your building, measure radio signals, check product compatibility or guarantee coverage. Real results depend on walls, construction, equipment, interference, placement and service quality.
