YOUR STARTING TOPOLOGY

Practical next steps

    Understand the basic home network layout

    In a typical home, the internet service reaches a modem or fibre ONT. A router connects your home network to that service and provides wired ports and often Wi-Fi. Other devices connect to the router directly, through a switch, or through additional access points or mesh nodes.

    A network switch adds Ethernet ports. A wireless access point adds Wi-Fi coverage at a location connected to the network, often by Ethernet. A mesh system uses multiple coordinated Wi-Fi units; the units need a suitable connection between them, either wireless or wired if supported.

    Choose the right home network topology

    The planner gives you a starting point, but the right design depends on the building, where the internet service enters, the devices that need dependable connections and whether you can run cable. These are common patterns—not guarantees based on floor area alone.

    One router for a compact home

    A single router is often the simplest starting point for a compact, mostly single-floor home. Put it in an open, central position where practical, then check signal and performance in the rooms that matter. Do not add an extender or mesh kit just because it is available; first identify where the connection becomes weak.

    Router plus wired access points

    If Ethernet can reach the rooms or floors that need better Wi-Fi, connect an access point there. The main router continues to manage the network, while the access point provides another Wi-Fi radio location. A switch can add wired ports when the router does not have enough. Check that the access point supports the network features and power method you intend to use.

    Mesh when new cabling is impractical

    A mesh system can help extend coverage across a larger or multi-floor home. The main unit connects to the modem or fibre ONT; additional nodes communicate with the main unit or other nodes. A node still needs a sufficiently strong link to the rest of the mesh. Placing a satellite in the very room where Wi-Fi is already unusable can leave it with a poor connection of its own. Start partway between the main unit and the weak area, then use the system's connection test and adjust.

    Extender or repeater for a limited dead zone

    A basic extender may be suitable for a small, specific coverage gap, but it repeats a wireless signal and must itself receive a usable signal. It is not a substitute for fixing a poor router location or a weak connection between floors. Compare performance at the actual device location before and after installation.

    What each network device does

    • Modem or fibre ONT: terminates the service connection provided by the ISP. Fibre services commonly use an ONT; the exact equipment depends on the provider.
    • Router: connects the home network to the ISP connection and typically handles routing, local addressing, firewall functions and often Wi-Fi.
    • Network switch: adds Ethernet ports so multiple wired devices or access points can connect to the local network.
    • Access point: provides Wi-Fi for nearby devices and normally connects back to the network by Ethernet.
    • Mesh node: extends a compatible mesh system using a wireless or, on supported models, wired backhaul.

    Some ISP gateways combine a modem or ONT interface, router, switch ports and Wi-Fi in one box. Before buying another router, check whether your existing gateway can provide the function you need and whether adding a second router would create an unnecessary double-router setup.

    Place equipment sensibly

    • Keep the main router in an open, raised location where practical—not inside a cupboard, behind a television or on the floor.
    • Try a central position relative to the rooms where people use Wi-Fi, while accounting for where the ISP connection and power are available.
    • Keep equipment away from large metal objects, dense obstructions and sources of radio interference where possible.
    • For mesh, place nodes where the link back to the main unit is still healthy. Move them in small steps and run the system's mesh test after each change.
    • For multi-floor homes, test the stairwell and the rooms above or below the router. Concrete, brick, metal and floor construction can change coverage substantially.
    • Connect stationary devices such as desktop PCs, TVs, consoles and network storage by Ethernet when practical, especially when stable performance matters.

    There is no universal router distance or guaranteed coverage radius. Building materials, neighbouring networks, antenna design, client devices and placement all affect the result. Use a real test in the rooms you care about rather than relying only on signal bars or the coverage number printed on a product box.

    Install, test and improve one step at a time

    1. Map the home: mark the ISP entry point, rooms where people work or stream, stationary devices, power outlets and possible cable routes.
    2. Record a baseline: test the connection beside the router and in the rooms with problems. Note download, upload, latency and whether the issue happens on one device or several.
    3. Improve the main router location: if practical, move it to an open position before buying additional equipment.
    4. Wire fixed devices: use Ethernet for devices that stay in one place and for access points where cable runs are feasible.
    5. Add coverage only where needed: choose a compatible access point, mesh node or extender based on the topology and the test results.
    6. Retest from the same locations: compare like with like, at similar times and with the same device where possible. Check both speed and stability.
    7. Secure and maintain the network: change default administrator credentials, use WPA2-AES or WPA3 where supported, keep firmware updated and disable features you do not use.

    When testing, remember that an internet speed test measures the path between your device and a test endpoint. It does not by itself map whole-home radio coverage. A wired test beside the router can help separate an ISP or router issue from a Wi-Fi coverage issue.

    Frequently asked questions about home network planning

    Do I need mesh Wi-Fi in a two-floor home?

    Not automatically. Some homes work well with a centrally placed router; others have floors, walls or layouts that weaken the signal. Test the rooms and floors first. If Ethernet can reach the second floor, a wired access point is another option.

    Is a mesh system better than a Wi-Fi extender?

    They solve related but not identical problems. Mesh systems coordinate multiple units as one managed network, while a basic extender repeats an existing wireless signal. The result depends on the product, placement and backhaul link. Neither can create a strong connection if its own link to the router is poor.

    Should I use Ethernet for gaming and video calls?

    Ethernet can reduce dependence on Wi-Fi signal quality and local wireless interference for a stationary device. It cannot remove delay or congestion elsewhere on the internet path, but it is a useful way to make the home-network part of the connection more predictable.

    Where should I put a mesh node?

    Start between the main unit and the area that needs better coverage, in an open location where the node still receives a good signal. Check the manufacturer's app or built-in mesh test, then adjust. Exact spacing varies by building and equipment.

    Will a faster internet plan fix weak Wi-Fi?

    Not necessarily. A faster ISP plan increases the available internet capacity, but it does not automatically improve signal through walls, router placement, local interference or a weak mesh backhaul. Diagnose the local network separately from the service speed.

    How many devices can one router support?

    There is no single reliable device-count limit for every router. Performance depends on the router model, Wi-Fi generation, device activity, radio conditions and the mix of applications. A device that is idle uses a different amount of capacity from one continuously streaming or uploading.

    Important

    This planner provides a learning recommendation based on your answers. It does not inspect your building, measure radio signals, check product compatibility or guarantee coverage. Real results depend on walls, construction, equipment, interference, placement and service quality.
