How to Share Your Wi-Fi Password Using a QR Code on Android and iPhone

Connect guests without reading out a long password. Learn the built-in QR and password-sharing methods, understand what the code exposes, and choose a safer way to give visitors access.

By Suraj Vishwakarma · Published by TEZZ CONNECT

When someone visits your home, the Wi-Fi question often arrives before the tea. Reading a long password aloud is inconvenient, and typing it character by character can lead to mistakes. A Wi-Fi QR code makes the process easier: the host displays a code, the guest scans it, and a compatible phone can offer to join the network.

Most importantly, you do not need to install a random QR app or upload your network password to a website. Many Android phones and recent Apple software include built-in ways to share Wi-Fi access. The exact menus depend on the phone maker and software version, so this guide explains the common routes and alternatives rather than promising that every device has the same button.

What is a Wi-Fi QR code?

A Wi-Fi QR code is a two-dimensional barcode that stores the information a device needs to recognise a wireless network. A typical code can include the network name (SSID), the security type, the password and a setting that indicates whether the network is hidden. When a phone camera or QR scanner recognises the code, it may display a prompt to join the network.

The QR code is a convenient container for connection details; it does not make the underlying Wi-Fi network more secure. In many common Wi-Fi QR formats, the password is encoded in a form that a person or app capable of decoding the code can read. Treat a screenshot, printed card or displayed code as sensitive information. Do not assume that the password is encrypted simply because it is shown as a pattern of black and white squares.

Scanning also does not guarantee an immediate connection. The guest may need to tap a confirmation, accept a system prompt, be within radio range and use a security mode supported by the device. A QR code cannot bypass a hotel sign-in page, a paid access portal, device registration or other network access controls.

Before you start: check these basics

  • Your phone is connected to the correct Wi-Fi network. The share option normally creates a code for the saved network selected in Settings. Check the network name before showing it.
  • You can unlock the host phone. The operating system may ask for a PIN, password, fingerprint or face authentication before revealing the code or password.
  • The guest device can scan QR codes. Try the default camera first. If it does not recognise the code, use the built-in QR scanner in Quick Settings or Control Centre if available.
  • The network password has not changed. A printed code or saved screenshot becomes stale after the router password or network name changes.
  • You are comfortable giving this person network access. A successful scan can allow the guest device to join the network. Use a guest network when you do not want visitors on your main home network.

Keep the phone and the QR code in good light. Avoid glare, cracked screens, tiny print and cropped corners. QR scanners need a clear view of the full code, including its outer positioning squares.

How to share Wi-Fi using a QR code on Google Pixel

On supported Pixel phones, Google documents a built-in sharing flow from the Internet settings. The wording may change slightly between Android releases, but the general path is:

  1. Open Settings on the Pixel phone.
  2. Tap Network & internet, then Internet.
  3. Confirm Wi-Fi is on and the phone is connected to the network you want to share.
  4. Tap the settings or gear icon beside the connected network.
  5. Tap Share.
  6. Verify your identity if the phone asks you to.
  7. Show the resulting QR code to the guest so they can scan it with their phone.

Google also documents a shortcut from Quick Settings on supported Pixel software: swipe down, tap Internet, confirm the connected network and choose Share Wi-Fi where that control is offered. If you do not see the shortcut, use the Settings route instead.

The guest should open the camera or QR scanner, point it at the displayed code and tap the network prompt if one appears. If the camera only takes a photo, try the phone's dedicated QR scanner or update the camera app and system software. Google's Pixel support page is the best reference for the current menu on Pixel devices.

How to share Wi-Fi using a QR code on Samsung Galaxy

Samsung Galaxy phones commonly provide a QR option in the details for the connected Wi-Fi network. Menu labels can vary with One UI version, carrier software and model, but try this sequence:

  1. Open Settings.
  2. Tap Connections, then Wi-Fi.
  3. Make sure the phone is connected to the network you intend to share.
  4. Tap the gear icon beside that network.
  5. Look for QR code near the bottom of the network details screen.
  6. Tap it and authenticate if prompted.
  7. Let the guest scan the code from their phone.

If the QR option is absent, do not assume the phone is faulty. The feature can depend on the model, region and software build. Check for a software update, search Settings for “QR code”, or consult Samsung Support for your exact Galaxy model. Samsung's support guidance describes QR-based Wi-Fi sharing on Galaxy phones, but the on-screen layout is not identical on every device.

Do not confuse Wi-Fi QR sharing with Quick Share. Quick Share is a nearby file-sharing feature; its QR code can help transfer files or establish a sharing session. It is not the same thing as a QR code containing your router's Wi-Fi credentials.

How to share Wi-Fi on iPhone

Apple provides more than one route, depending on the iPhone software version and the devices involved. You may be able to display a network QR code, use Apple's nearby password-sharing prompt, or reveal a saved password and share it manually.

Option 1: show a network QR code

  1. Open the iPhone's Settings and go to Wi-Fi.
  2. Find the connected network and tap its information button.
  3. If your software offers Show Network QR Code, select it.
  4. Authenticate with Face ID, Touch ID or your passcode if asked.
  5. Let the guest scan the code with a compatible phone camera or QR scanner.

The option may not appear on every iPhone or software release. If it is missing, use Apple's built-in password-sharing method below or reveal the password through the supported Passwords or Wi-Fi settings screen. Apple's current iPhone guide documents the QR-code option on supported software.

Option 2: use Apple's nearby Share Password prompt

Apple's automatic sharing is designed for nearby Apple devices. Before trying it, check the requirements:

  • Both devices should have current compatible versions of iOS, iPadOS or macOS.
  • Wi-Fi and Bluetooth should be switched on for both devices.
  • Each person should be signed in to their Apple Account.
  • The Apple Account email address or phone number for each person should be saved in the other person's Contacts.
  • The sharing iPhone should be unlocked and connected to the Wi-Fi network.
  • Keep the devices close together and turn off Personal Hotspot if Apple instructs you to do so.

Ask the guest to open Wi-Fi settings and tap the name of the network. A prompt should appear on the connected iPhone asking whether to share the password. Tap Share Password, then Done. If the prompt does not appear, bring the devices closer, confirm the contact details and wireless settings, then try again.

Option 3: reveal a saved password

If automatic sharing is unavailable, an authorised user can reveal a saved Wi-Fi password on supported iPhone software. Open Settings, tap Wi-Fi, tap the information button beside the network and select the Password field. Authenticate to view or copy it. On supported versions, the Passwords app also stores saved Wi-Fi credentials. Share the password privately rather than sending it in a public group chat.

How a guest scans the code on Android or iPhone

On many Android phones, open the Camera app in its normal photo mode and point it at the QR code. Wait for a banner or link to appear, then tap it. Some models have a dedicated Scan QR code tile in Quick Settings. If the camera does not offer a network action, open the scanner from Quick Settings or the manufacturer's camera tools.

On iPhone, open Camera, point it at the code and tap the detected Wi-Fi notification if it appears. Keep the phone steady and ensure the entire code is visible. If no notification appears, check that QR scanning is enabled in Camera settings, try another built-in scanner, or use the password-sharing route.

After the prompt is tapped, the guest device may ask for confirmation before joining. Wait for the Wi-Fi symbol or connected status, then open a website to check access. A device can join a router successfully but still have no internet if the broadband connection is down or the router has a separate access restriction.

Can an Android phone share Wi-Fi with an iPhone?

Usually, yes, when the Android phone can display a standard Wi-Fi QR code and the iPhone camera or scanner recognises it. The QR code is a device-independent way to represent the network details; it is not limited to phones from the same manufacturer. The guest may still need to confirm the connection, and support can vary with camera software and network security settings.

The reverse is also possible on supported iPhone software when it displays a network QR code that the Android camera can read. Apple's nearby Share Password prompt is different: it is intended for compatible Apple devices and should not be expected to appear on an Android phone. For mixed Android-and-iPhone households, a visible QR code or private manual password sharing is often the more practical cross-platform method.

Before relying on a QR code for an event, test it with one Android device and one iPhone if your visitors use both platforms. This catches camera and compatibility differences before several guests arrive.

What information is inside a Wi-Fi QR code?

A common Wi-Fi QR payload identifies the network name and security type and may include the password and a hidden-network flag. The exact contents depend on how the code was generated. The scanner interprets these details so the phone can prepare a connection request.

This has an important privacy implication: a person who photographs a code may be able to decode its contents later, even if they are not currently in range of the router. A screenshot is not a one-time invitation. Anyone who receives the image could potentially reuse the credentials until you change them or otherwise revoke access.

QR codes do not normally grant a special identity or temporary access by themselves. They share the same Wi-Fi credential that a person could type manually. If the password is shared widely, the router generally cannot tell which guest learned it from the code and which one typed it in. For that reason, a guest network with its own password is preferable when the router supports it.

Is it safe to put your Wi-Fi QR code on a wall?

It depends on the network and the people who can see the code. A QR code placed inside a private home for trusted visitors is different from one displayed in a shop window, reception area or public waiting room. If the code contains the password for your main home network, anyone who can photograph it may be able to attempt to join.

For a home network, consider these precautions:

  • Create a guest Wi-Fi network. Many routers let you create a separate SSID and password for visitors. Where supported, enable guest isolation so guest devices cannot directly reach devices on your main local network.
  • Use a strong, unique password. Avoid reusing the same password for the router administrator account, email or other services.
  • Use modern Wi-Fi security. Prefer WPA3-Personal when all devices support it, or WPA2-AES where compatibility requires it. Avoid obsolete WEP and legacy WPA modes.
  • Limit how widely the code is displayed. Keep a printed guest code in a controlled area rather than on an exterior window or public social media post.
  • Rotate access when needed. If the code or password has been exposed, change the guest network password and replace the printed code.
  • Keep router firmware current. Security updates help address known vulnerabilities in the router itself.

Guest isolation is not identical on every router. Some guest networks allow guests to communicate with one another, reach local printers or access selected devices. Read the router's settings and test the behaviour rather than assuming the word “guest” guarantees complete separation.

Should you use a guest network or share your main Wi-Fi?

For a one-time visit from a trusted person, sharing the main network may be acceptable if you understand the access it provides. For frequent visitors, tenants, customers, contractors or events, a separate guest network is usually easier to manage. It gives you a distinct password that can be changed without reconnecting every device in your home.

For a business, consider whether guest access needs a usage policy, time limit, bandwidth limit or client isolation. These controls depend on the router or access point. A simple printed QR code is convenient, but it is not a substitute for a managed wireless network.

Why the Wi-Fi QR code may not work

The camera does not recognise the code

Increase screen brightness, clean the camera lens, move the phone slightly farther away and make sure the complete code is visible. Avoid glare from overhead lights. Try the built-in QR scanner rather than the camera app if the phone has one. If the code is printed, make sure it is not blurred, folded or cropped.

The guest scans it but nothing happens

Some camera apps display a banner that must be tapped; scanning does not always connect automatically. Check notifications and the screen for a Wi-Fi action. If the guest phone only shows a string of text, its scanner may not support the Wi-Fi payload format. Use a compatible scanner built into the operating system or enter the password manually.

The phone says the password is incorrect

The code may be old, may refer to another network or may have been generated before the router password changed. Generate a fresh code from the currently connected network. Confirm the exact SSID, including spaces, punctuation and capitalisation. If you recently changed router security settings, reconnect the host phone and generate a new code.

The device joins Wi-Fi but has no internet

QR sharing only provides connection details; it cannot repair a broadband outage. Check whether another device on the same network can browse. Restart the router only if appropriate, check the ISP's outage information and test the connection with a known working device. If the guest network has a captive portal, the guest may need to open a browser and complete its sign-in page.

The QR option is missing from Settings

Search Settings for “Share”, “QR code” or “Wi-Fi”. Confirm that the phone is connected to the network and check for a system update. Manufacturers move options between software versions, and not every model exposes the same feature. Use the official support page for the exact model rather than installing an unknown QR utility.

Apple's Share Password prompt does not appear

Keep the devices close, unlock the sharing iPhone, check that both devices have Wi-Fi and Bluetooth enabled and verify that each person's Apple Account contact details are saved in the other's Contacts. Turn Personal Hotspot off if it is enabled. Restarting both devices can help if the prompt remains absent. Apple recommends entering the password manually if automatic sharing still fails.

A device cannot join a hidden or enterprise network

Some networks need additional settings that a basic consumer QR code cannot fully describe, such as enterprise identity credentials, certificates, a username or a one-time portal login. A hidden SSID can also require the device to handle the network name and security details correctly. Ask the network administrator for the approved onboarding method instead of repeatedly scanning a generic code.

Can you create a Wi-Fi QR code manually?

Some router administration pages and operating systems can display or export a QR code for a saved network. If you create one manually, you need the exact network name, the correct security type and the current password. A spelling error or wrong security selection can make the code unusable.

For most people, the phone's built-in Share function is the safer and simpler route because it takes the details from a saved network. If you use a third-party generator, check whether it processes the information locally in your browser or uploads it to a remote service. A website asking you to paste your home Wi-Fi password is receiving a sensitive credential; do not proceed unless you understand and trust its handling of that data.

Never upload a screenshot of your router label, password card or QR code to a public forum to ask why it does not work. Those images can reveal the credentials. If you need technical help, obscure the password and QR pattern first, or create a temporary guest network for troubleshooting.

What if you forgot the Wi-Fi password?

If your phone is already connected, supported Android and Apple software may let you display a QR code or reveal the saved password after authentication. On iPhone, the Wi-Fi details or Passwords app can show saved credentials on supported versions. On Pixel, the network Share option can display the QR code. On other Android phones, look for the manufacturer's Wi-Fi sharing control.

If no connected device can reveal the password, check the router's administration app or the label supplied with the router, provided the password has not been changed. Your internet provider may also have a router management app. As a last resort, an authorised administrator can change the Wi-Fi password in the router settings; remember that all devices using the old password will need to reconnect.

A router reset is not the first troubleshooting step. A factory reset can erase the ISP configuration, custom network name, port rules and other settings. Contact the ISP or consult the router manual before resetting equipment supplied by a broadband provider.

Does sharing a Wi-Fi QR code make the internet faster?

No. A QR code only makes it easier to pass connection information to another device. It does not increase broadband speed, improve Wi-Fi signal strength or add capacity to the router. Once connected, the guest device shares the available wireless airtime and internet connection with other devices according to the router's capabilities and network conditions.

If the connection becomes slow when visitors arrive, the cause may be weak signal, interference, a congested Wi-Fi band, simultaneous downloads or a broadband plan with limited capacity. Place the router in an open central location, use a suitable Wi-Fi band and check actual download, upload and latency performance. Sharing the password more efficiently does not change these underlying limits.

A quick checklist before sharing Wi-Fi with guests

  • Confirm the correct network is selected.
  • Prefer a guest network for visitors you do not want on your main LAN.
  • Generate the code from the phone's built-in Wi-Fi settings where possible.
  • Keep the QR code visible only to the intended guest.
  • Ask the guest to scan and tap the join prompt.
  • Confirm the device is connected and can reach the internet.
  • Remove or replace printed codes if the password changes or the code is exposed.
  • Never post a main-network QR code publicly.

Frequently asked questions

Can I share Wi-Fi from Android to iPhone with a QR code?

Yes, when the Android phone can display a standard Wi-Fi QR code and the iPhone camera or scanner recognises it. The iPhone may show a prompt that the guest must tap. Apple's automatic nearby Share Password prompt is intended for compatible Apple devices, not Android phones.

Can an iPhone generate a Wi-Fi QR code?

On supported iPhone software, open Wi-Fi settings, select the network's information screen and look for Show Network QR Code. If the option is not present, use Apple's nearby password-sharing prompt or reveal the saved password through supported settings.

Do guests need an app to scan a Wi-Fi QR code?

Usually not. Many current Android and iPhone camera apps recognise QR codes. Some Android devices provide a separate QR scanner in Quick Settings. If the default camera does not recognise the code, try the built-in scanner before installing another app.

Does a Wi-Fi QR code show the actual password?

The code commonly encodes the network name, security type and password in a machine-readable format. A person with a suitable decoder may be able to extract the details. Treat the QR code as sensitive and do not publish it openly.

Can I revoke a Wi-Fi QR code after sharing it?

The code itself usually has no independent expiry. If it contains the same password used by the network, changing that password invalidates old copies. A separate guest network makes it easier to rotate guest access without changing the main network password.

Why does my Samsung phone not show a QR code option?

Availability and menu placement can vary by Galaxy model, region and One UI version. Check that you are connected to the intended network, search Settings for QR code and consult Samsung Support for your exact model.

Why does Apple's Share Password feature not work with Android?

Apple's nearby Share Password prompt relies on Apple device and contact requirements. For Android guests, use a Wi-Fi QR code if the iPhone offers one, or share the password privately.

Is a guest Wi-Fi network safer than sharing the main password?

It can be. A guest network provides separate credentials and may support client isolation, which can limit access to devices on the main network. Confirm the router's actual guest-network controls because features differ by model.

Will a QR code connect a guest to hotel or office Wi-Fi?

It may help with the initial network details, but hotels and offices can require a captive portal, account, voucher, device registration or enterprise credentials. Follow the organisation's approved connection instructions.

What should I do if a QR scan connects but there is no internet?

Check whether other devices can browse, confirm that the guest network has internet access and complete any captive-portal sign-in. The QR code does not diagnose or repair a broadband or router outage.

Can I print my Wi-Fi QR code?

Yes, but print a guest-network code rather than your main credentials if possible. Keep the printout in a controlled place and replace it after changing the password. Anyone who can photograph the code may be able to reuse it.

Does a QR code work with every Wi-Fi security type?

No. Device support and QR format compatibility vary. Enterprise networks, certificate-based authentication, captive portals and some legacy security configurations may require a different onboarding process from a simple home Wi-Fi QR code.
