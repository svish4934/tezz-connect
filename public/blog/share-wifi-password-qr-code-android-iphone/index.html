How to Share Your Wi-Fi Password Using a QR Code on Android and iPhone

Share a home Wi-Fi connection more easily with built-in QR and password-sharing features on supported Android and Apple devices.

A Wi-Fi QR code can let a guest join a wireless network without manually typing its password. Many recent Android phones can display a network-sharing QR code, and Apple devices offer built-in password sharing and QR options on supported software. The exact menus vary by device and operating-system version.

Share a network from Android

On many Android devices, open Settings, go to Network & internet or Connections, select the connected Wi-Fi network and choose Share. The phone may ask you to verify your identity before displaying a QR code. Your guest can scan it with the camera or a compatible QR scanner to join the network.

Share a network from iPhone or iPad

Apple devices can share a saved Wi-Fi password with nearby contacts when the devices meet Apple’s requirements. On supported current software, you can also open the saved Wi-Fi network’s details and use the option to show a network QR code. Menu labels and availability can differ by software version.

What information does the QR code contain?

A Wi-Fi connection QR code can encode the network name and the credentials needed to join it. Treat it like a password: anyone who can scan a valid code may be able to connect, depending on the network’s security settings.

Share safely with guests

Show the code only to people you intend to give access to. Avoid posting it publicly, sending it to large groups or leaving a printed code in a public area. If you regularly host visitors, consider using a separate guest network with access restrictions rather than sharing the main network credentials.

Avoid unnecessary third-party generators

You usually do not need to upload your Wi-Fi name and password to an unfamiliar website to create a QR code. Prefer the built-in sharing feature on your phone. If you use another tool, understand where the credentials are processed and stored before entering them.

If the QR code does not work

Check that the network name and password have not changed, that the guest is scanning the full code and that the phone supports the relevant Wi-Fi security type. Some cameras may display the network details without automatically joining; the guest may need to confirm the connection.
